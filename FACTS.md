## What V28 adds

A ten-unit assembly: eight relays connected in a 32-tick unidirectional ring (edge weight -6), plus an original 59-tick clock and a separate silent reader. Ring unit 0 feeds the reader through weight -2, and clock unit 9 feeds the reader through weight -4. All added wire lengths are zero. The reader has **no return edge** to the memory.

There are no externally supplied read cues in the primary experiment after the initial memory write. Clock queries are generated by the original autonomous loop.

A clock beat spans TWO ticks; its two-bit window is ring(t) OR ring(t+1). A reader answer is detected at t+4 or t+5. The phase label is computed by the external measurement script relative to the known initial write time; the reader itself never sees this label.

## Actual results

- 27 stored patterns: 1 empty, 6 one-hot, 20 sparse random (xorshift32 seed 2463534242, Bernoulli p≈0.32).
- 71 clock windows per pattern during tick range [180,4400); 1,917 / 1,917 answers matched; 819 positive.
- Zero clock-window false positives, zero false negatives, zero unclocked reader beats in the audited interval; all 27 ring patterns stayed unchanged at the measured pre/post phases.
- The native 59-tick clock visits all 32 starting phases of a 32-tick ring in 32 consecutive clock queries (59 mod 32 = 27, coprime).
- On the chosen random-memory ablation: 35 positive windows with both wires, zero positive reader outputs with either read wire removed.
- Manual single-slot reader: **190 / 192** on the independent diagnostic, NOT 192/192; false responses at pattern index 1, slots 13 and 14.
- All-ones pattern: memory does not remain stable; only 55 / 71 queries match the intended dense pattern. V27's finite-window variance trap remains.
- Preserving the ring during read is expected from the one-way topology; it is not evidence for a protected endogenous read-undo mechanism.

## Frequent false claims to prevent

1. "V28 learned to read." False: weights, topology and clock are fixed. Only the readout is endogenous.
2. "V28 retrieves one arbitrary selected bit." False for its primary circuit: it reports a two-slot OR, and an external observer labels clock phases.
3. "The ring has 32 reliable bits of unrestricted capacity." False: all-ones fails; random sparse conditions were tested.
4. "Any tiny input noise is harmless." Untested in V28; V27 already documented a narrow robust weight regime.
5. "No measurement changes the ring because of discovered neural protection." False: the reader has no feedback path.
6. "V9, V24 and V25 algorithms are implemented in V28." False: they informed the question, but this machine uses the exact V27 core.
7. "The graph is literally biological neurons." False: a deliberately reduced numerical feedback controller.
